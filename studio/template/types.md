# Design types

The types Claude sorts designs into. Each type is a `##` heading (its name), an `id:` line, a definition paragraph, and a bulleted list of typical traits. Claude only changes this file when you say yes to a proposed change. "Unsorted" is built in and doesn't go here.

## Bold and loud
id: bold-and-loud
Designs that grab attention first and explain second: big confident type, strong colour, and layouts that break the grid on purpose.
- Oversized or expressive headlines
- High-contrast, saturated colour
- Few elements, each one large
- Playful or unexpected layout

## Dark and glowing
id: dark-and-glowing
Dark backgrounds where light does the work: glows, gradients and bright accents that make key elements feel lit from inside.
- Near-black or deep-colour backgrounds
- Neon or gradient accents
- Light used to lead the eye
- Sleek, technical or night-time mood

## Calm and structured
id: calm-and-structured
Quiet, orderly designs where a clear grid and restrained palette let the content lead.
- Generous white space
- Clear grid and alignment
- Muted or limited palette
- Readable, unshowy type
